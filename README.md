# Study Planner MVP

This project is a fully static study planner built with HTML, CSS, and vanilla JavaScript.

## Features
- Dashboard with greeting, current session, progress and session list
- Session view with five subjects and checklist items
- Resource links that open in new tabs
- Quiz flow with scoring and answer review
- Persistent storage with localStorage
- JSON-driven sessions and quizzes

## Run locally
Open the folder in a browser directly, or serve it from a simple local server:

```bash
cd "c:\Games\My projects\study nowie"
py -m http.server 8000 --bind 127.0.0.1
```

Then open http://127.0.0.1:8000/index.html
